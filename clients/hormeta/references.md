> Liens vers des vidéos **approuvées**, avec une explication précise de ce qu'il faut reproduire et éviter.

## Format d'une entrée

```
### Référence N — titre court
Vidéo de référence : [lien]
Emplacement local du fichier : chemin Windows
Approuvée par / le : nom, date
À reproduire : ...
À éviter : ...
```

> Exemple de format uniquement, **non approuvé et sans valeur de directive** : « À reproduire : démarrage directement sur l'action, coupes courtes, texte discret. À éviter : longue introduction avec le logo. » Ne pas appliquer cet exemple à Hormeta.
